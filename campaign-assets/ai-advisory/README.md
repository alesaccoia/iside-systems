# AI Advisory creative kit

Campaign dedicated only to AI Advisory. It uses actual Noto Sans glyph widths
and explicit safe areas, so no element is placed from a character-count estimate.

- carousel: five cards in 1:1, 1.91:1 and 4:5, PNG and editable SVG
- video: silent 15-second H.264 MP4 in 16:9, 1:1 and 9:16

Card order: Direction, Priority, Workflow, Governance, Advisory.

Rebuild: python3 build.py
