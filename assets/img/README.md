# Immagini

## Ritratto (pagina Chi sono / About)

Salva qui la foto con questo nome esatto:

    assets/img/alessandro.jpg

- formato consigliato: JPG, ritaglio verticale 4:5
- dimensione consigliata: 900 × 1125 px (viene mostrata a ~240 px, il doppio serve per gli schermi retina)
- peso: sotto i 300 KB

Se il file non c'è, il blocco ritratto si nasconde da solo: la pagina resta
valida, senza icona di immagine rotta.

Per cambiare nome file o didascalia, vedi `portrait_*` nei dizionari
`L_IT` / `L_EN` di `build.py`, poi rilancia `python3 build.py`.
